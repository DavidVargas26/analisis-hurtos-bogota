# Análisis de hurtos en Colombia


¿Cuál es el análisis de datos?
Este proyecto realiza un análisis exploratorio de los registros de hurto a personas reportados en Colombia, con énfasis en los eventos ocurridos en Bogotá.
El objetivo es identificar patrones temporales en los hechos de hurto, analizar su comportamiento a través de los años y reconocer periodos donde la ocurrencia del fenómeno presenta mayores concentraciones.
Pregunta de investigación:
¿Cómo ha evolucionado el hurto a personas en Bogotá y qué patrones temporales pueden identificarse a partir de los registros históricos disponibles?

Descripción de los datos
El conjunto de datos contiene registros oficiales de hurto a personas reportados por las autoridades competentes.
Cada fila representa un registro asociado a una fecha y ubicación geográfica específicas.
El dataset contiene 654.716 registros y 6 variables:

- FECHA HECHO: fecha en que ocurrió el hecho reportado.
- COD_DEPTO: código del departamento.
- DEPARTAMENTO: nombre del departamento.
- COD_MUNI: código del municipio.
- MUNICIPIO: nombre del municipio.
- CANTIDAD: número de casos registrados.
Los datos permiten realizar análisis descriptivos, temporales y comparativos sobre la evolución del hurto a personas.
